# 헐크 스매쉬 💚💥

눈에 보이는 건 전부 부숴라 — 아무 생각 없이 다 부수는 킬링타임용 파괴 게임.

**플레이:** https://hulk-smash-fawn.vercel.app/

## 조작

| 키 | 동작 |
|---|---|
| ← → / A D | 이동 (러닝) |
| ↑ / W | 점프 — **착지 시 미니 슬램 충격파** |
| **Z / SPACE (꾹)** | 주먹 연타 — 잽 → 훅 → 양손 해머 콤보 |
| X | 메테오 슬램 (STAGE 2 해제) — 화염 낙하 + 대폭발 |
| C | **합장** (STAGE 3 해제) — 양팔을 활짝 벌렸다 앞으로 쫙 편 채 마주쳐 전방 폭풍 파면 |
| V | 혜성 돌진 (STAGE 4 해제) — 관통 + 소닉붐 피니시 |
| R | 분노 폭발 (STAGE 5 해제) — **레드 헐크 변신**(+14% 거대화) + 좀비 웨이브 |
| B | 낙뢰 폭풍 (STAGE 6 해제) — 하늘에서 번개가 화면 전체에 연쇄 낙하 |
| Q·E·F·T·G | **보스 격파 보상 스킬** (계속 누적, 중복 선택 시 레벨업) |
| O | **스킬 자동 사용** 토글 (STAGE 5 해제) — 보유한 스킬이 쿨타임마다 알아서 발동 |
| **SPACE** | 클리어 화면에서 **다음 스테이지로** (보상 선택 중엔 카드를 골라야 진행) |
| P / ESC | 일시정지 · M 음소거 |

모바일 터치 컨트롤 지원 (핀치 확대 방지).

## 게임 시스템

- 스테이지의 **모든 사물을 부수면 클리어**. 헐크의 덩치는 **STAGE 5까지** 커지고(그 뒤로는 고정), 파워는 계속 강해진다.
- **앞을 가로막는 사물은 부숴야 지나갈 수 있다** — 길을 막은 건물·집기를 남겨두고 전진할 수 없다.
- **콤보**: 끊기지 않고 연속 파괴하면 점수 배수가 계속 오르고(상단 중앙 HUD), 분노 게이지도 더 빨리 찬다. **상한 없음**. 3.5초 안에 다음 걸 부수지 못하면 리셋되고, 보스에게 맞아도 끊긴다.
- **피버 타임**: 스테이지 사물의 70%를 끊김 없이 부수면 10초간 발동 — 모든 것이 한 방에 터지고 금빛 화면 + 종료 시 `콤보 × 100` 보너스. **피버가 끝나도 콤보는 그대로 이어진다** — 대신 12초 재충전 쿨타임 동안은 다시 발동하지 않는다(HUD에 남은 시간 표시).
- **파워업 드롭**: 부술 때 확률로 아이템이 떨어진다 — ⚡공격력 2배(10초)·➕HP 회복(체력이 깎였을 때만)·불꽃(분노 +30). 다가가면 자석처럼 흡수.
- **10스테이지마다 보너스 판**: 사물 없는 아레나에서 **화면 한가운데 땅을 뚫고 좀비 헐크 떼**가 끝없이 솟아올라 왼쪽의 헐크를 향해 밀려온다. **이 판에서는 헐크 HP가 깎이지 않는다** — 순수 학살 스테이지. 좀비 헐크는 **플레이어 헐크와 완전히 같은 실루엣**으로 그려지고, 팔레트·머리·눈빛만 좀비로 바뀐 채 **두 팔을 앞으로 뻗고** 걸어온다. **변종 6종**이 회차마다 하나씩 늘어나며 섞여 나온다 — 같은 변종 안에서도 덩치가 제각각이라 거구일수록 느리고 점수가 크다.
  - **좀비 헐크**(초록, 기준) · **좀비 그레이**(작고 매우 빠름, 약함) — 1회차부터
  - **좀비 레드헐크**(붉은색, 빠르고 아프다) · **좀비 브루트**(거구, 굼뜨지만 가장 강한 일격) — 2회차부터
  - **감마 뮤턴트**(보라, 빠르고 점수 큼) — 3회차부터
  - **좀비 본크러셔**(뼛빛, 크고 단단) — 4회차부터 할당량을 전부 때려눕히면 클리어. 회차가 오를수록 수·이동 속도·공격력·밀려오는 속도가 모두 오른다(1회차 40마리·데미지 7·스폰 0.17초 → 5회차 96마리·데미지 15·스폰 0.12초 → 9회차 152마리·데미지 24·스폰 0.07초). 한 마리당 점수가 일반 좀비의 6배라 콤보를 이어가면 점수가 폭발한다. (보스 스테이지보다 우선)
- **5스테이지마다 보스 1:1** — 빌런마다 **고유 공격 패턴**을 가진 5종 로테이션, 회차마다 강해진다.
  - **센티넬** — 눈에서 뻗는 **광학 빔**을 길게 발사. 지면에 서 있으면 계속 지져지니 **점프로 피해야 한다**.
  - **어보미네이션** — 짐승처럼 **멈추지 않는 연속 돌진**. 벽에 박아도 곧장 되돌아 달려든다.
  - **모독** — 이마 캐논 **3방향 확산 사격**. 탄을 다 쏘면 재장전 그로기가 온다.
  - **타노스** — **인피니티 스냅**. 크게 예비동작을 잡고 손가락을 튕기면 아레나 전체에 보라 충격파가 퍼진다. **점프가 유일한 회피**. 그로기 전엔 장갑으로 피해 감소.
  - **닥터 둠** — **둠봇 소환** + 마법 볼트 연발.
- **클리어 랭크 S/A/B/C**: 클리어 시간·최대 콤보·(보스전은 남은 체력, 일반 스테이지는 피버 도달)로 판정하고 등급만큼 보너스 점수(S는 스테이지 점수의 50%).
- **파괴 마일스톤**: 누적 100·300·500·1,000·2,500·5,000…번째 파괴마다 대형 연출 + 보너스 점수.
- **헐크 버전 9종(코믹스 인격)**: 색만 바뀌는 게 아니라 **머리 모양·수염·눈빛·체형(키·어깨너비·몸통·다리 길이·근육 두께)** 까지 달라진다. **처음부터 전부** 고를 수 있고, 시작 화면과 일시정지 화면에서 언제든 교체되며 선택은 브라우저에 저장. (분노 변신 중엔 몸만 레드 헐크가 되고 머리·장비는 유지)
  - **새비지 헐크** — 원조 녹색 헐크, 통제할 수 없는 분노 · 헝클어진 흑발 · 기준 체형
  - **그레이 헐크 / 미스터 픽싯** — 교활한 라스베이거스 해결사 · 올백 머리 · 가장 날렵하고 다리가 긺
  - **프로페서 헐크** — 배너의 지능 + 헐크의 힘 · 단정한 가르마 · 키 크고 균형 잡힌 체형
  - **마에스트로** — 디스토피아 미래의 폭군 · 백발 장발 + 수염 · 두꺼운 몸통에 짧은 다리
  - **데빌 헐크** — 가장 냉혹한 인격 · 검은 장발, 붉은 눈 · 넓은 어깨의 거구
  - **레드 헐크** — 로스 장군, 변신 후에도 이성 유지 · 각진 군인 체형
  - **월드워 헐크** — 우주에서 돌아온 복수 · 짙은 녹색, 주황 눈 · 최대 체급
  - **검투사 헐크** — 플래닛 헐크 / 라그나로크의 챔피언 · 붉은 볏 투구 · 견갑 · 전완 브레이서 · 강철 킬트
  - **얼티밋 헐크** — 지구-1610, 민머리에 훨씬 잔인함 · 마르고 길쭉한 근육질

- **보스 보상**: 어스퀘이크(Q)·철골 투척(E)·헐크 포효(F)·토네이도 스핀(T)·기가 스톰프(G) 중 택1 — 전부 모으면 레벨업 모드.
- **좀비 4종**: 워커 · 러너(빠름, 3~) · 브루트(거구·점수 2.2배, 6~) · 크롤러(낮게 기어옴, 9~) — 스테이지가 오를수록 험한 놈들이 섞이고, 피부톤·복장·안전모/모자가 제각각.
- **분노 변신(R)**: 게이지를 채워 발동하면 붉은 폭주 형태로 변신, 좀비 떼가 몰려오고 처치할수록 분노 지속 연장.
- 스테이지가 오를수록 **부술 것이 계속 늘어난다** — 동상(3)·네온 광고탑(5)·급수탑(7)·타워 크레인(9)·마천루(11)가 차례로 등장하고, 스테이지가 길어지는 동시에 사물 간격도 좁아져 더 빽빽하게 들어찬다(STAGE 6 약 27개 → 21 약 51개 → 49 약 74개). 내구도도 공격력보다 빠르게 올라 거대 구조물은 갈수록 여러 방을 버틴다.
- **광역 공격은 화면 안까지만** 닿는다 — 메테오 슬램·합장·포효의 사거리에 상한을 둬서, 화면에 보이지도 않는 건물이 부서지는 일이 없다.
- 테마 5종 순환(도심·노을 항구·네온 밤거리·폭풍 전야·군사 기지) — **테마별 BGM 무드**(에픽 록/서정/신스웨이브/긴장/행진곡)와 조성이 함께 바뀐다.
- 히트스톱·슬로모션·줌킥·날아가는 차량 물리·화염/연기/파편 — 전부 외부 리소스 없는 단일 파일 (사운드도 WebAudio 신디사이저).
- **자동 성능 조절**: 실제 프레임 간격을 계속 지켜보다가 느려지면 렌더 해상도·파티클 상한·발광 이펙트를 자동으로 낮추고, 회복되면 되돌린다. 효과음도 프레임/시간당 상한을 둬서 오디오 노드 폭주로 음악이 끊기지 않게 한다.

## 파일

- `index.html` — 배포용 (Vercel이 그대로 서빙). **`hulk-smash.html`에서 생성됨.**
- `hulk-smash.html` — 소스 (Claude 아티팩트 형식: 문서 래퍼 없이 본문만).

수정은 `hulk-smash.html`에 하고, `index.html`은 본문을 `<!doctype html>` 래퍼로 감싸 재생성한다. 배포 채널은 둘: GitHub push → Vercel 자동 배포, 그리고 Claude 아티팩트 재게시.
