# 헐크 스매쉬 💚💥

눈에 보이는 건 전부 부숴라 — 아무 생각 없이 다 부수는 킬링타임용 파괴 게임.

**플레이:** https://hulk-smash-fawn.vercel.app/

## 조작

| 키 | 동작 |
|---|---|
| ← → / A D | 이동 |
| ↑ / W | 점프 |
| **Z / SPACE (꾹)** | 주먹 연타 — 잽 → 훅 → 양손 해머 콤보 |
| X | 슬램 (STAGE 2 해제) |
| C | 천둥박수 (STAGE 3 해제) |
| V | 돌진 (STAGE 4 해제) |
| R | 분노 폭발 (STAGE 5 해제, 게이지 필요) |
| P / ESC | 일시정지 · M 음소거 |

모바일 터치 컨트롤 지원.

## 게임

- 스테이지의 **모든 사물을 부수면 클리어** — 실패 없음, 순수 카타르시스.
- 스테이지가 오를수록 헐크가 커지고 강해지며 스킬이 하나씩 열린다.
- 테마 순환: 도심 → 노을 항구 → 네온 밤거리 → 폭풍 → 군사기지 (무한 진행).
- 히트스톱·슬로모션·날아가는 차량 물리·화염/연기/파편, 신디사이저 록 BGM과 효과음 — 전부 외부 리소스 없는 단일 파일.

## 파일

- `index.html` — 배포용 (Vercel이 그대로 서빙). **`hulk-smash.html`에서 생성됨.**
- `hulk-smash.html` — 소스 (Claude 아티팩트 형식: 문서 래퍼 없이 본문만).

수정은 `hulk-smash.html`에 하고, `index.html`은 본문을 `<!doctype html>` 래퍼로 감싸 재생성한다.
