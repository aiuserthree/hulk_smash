# 헐크 스매쉬 💚💥

눈에 보이는 건 전부 부숴라 — 아무 생각 없이 다 부수는 킬링타임용 파괴 게임.

**플레이:** https://hulk-smash-fawn.vercel.app/

## 조작

| 키 | 동작 |
|---|---|
| ← → / A D | 이동 (러닝) |
| ↑ / W | 점프 — **착지 시 미니 슬램 충격파** |
| **Z / SPACE (꾹)** | 주먹 연타 — 잽 → 훅 → 양손 해머 콤보 |
| X | 메테오 슬램 (STAGE 2 해제) — 화염 낙하 + 대폭발 |
| C | 합장 박수 (STAGE 3 해제) — 전방 폭풍 파면으로 전부 날려버림 |
| V | 혜성 돌진 (STAGE 4 해제) — 관통 + 소닉붐 피니시 |
| R | 분노 폭발 (STAGE 5 해제) — **레드 헐크 변신**(+35% 거대화, 모바일은 화면 크기에 맞춰 완화) + 좀비 웨이브 |
| B | 낙뢰 폭풍 (STAGE 6 해제) — 하늘에서 번개가 화면 전체에 연쇄 낙하 |
| Q·E·F·T·G | **보스 격파 보상 스킬** (계속 누적, 중복 선택 시 레벨업) |
| O | **스킬 자동 사용** 토글 (STAGE 5 해제) — 보유한 스킬이 쿨타임마다 알아서 발동 |
| P / ESC | 일시정지 · M 음소거 |

모바일 터치 컨트롤 지원 (핀치 확대 방지).

## 게임 시스템

- 스테이지의 **모든 사물을 부수면 클리어**. 스테이지가 오를수록 헐크가 커지고 강해진다.
- **앞을 가로막는 사물은 부숴야 지나갈 수 있다** — 길을 막은 건물·집기를 남겨두고 전진할 수 없다.
- **콤보**: 끊기지 않고 연속 파괴하면 점수 배수가 계속 오르고(상단 중앙 HUD), 분노 게이지도 더 빨리 찬다. 3.5초 안에 다음 걸 부수지 못하면 리셋.
- **피버 타임**: 스테이지 사물의 70%를 끊김 없이 부수면 10초간 발동 — 모든 것이 한 방에 터지고 금빛 화면 + 종료 시 보너스 점수.
- **파워업 드롭**: 부술 때 확률로 아이템이 떨어진다 — ⚡공격력 2배(10초)·★거대화(10초)·➕HP 회복·불꽃(분노 +30). 다가가면 자석처럼 흡수.
- **5스테이지마다 보스 1:1** — 타이탄(메카) → 베헤모스(괴수) → 골리앗(공성 전차) → 옵시디언(암석 골렘, 그로기 전엔 장갑으로 피해 감소) → 헤카테(좀비 여왕, 전투 중 하수인 소환) 5종 로테이션, 회차마다 강해짐. 보스는 아레나 한가운데에서 시작한다. 보스전에서만 헐크 HP가 깎이고(예고 동작을 회피!), 쓰러지면 재도전.
- **보스 보상**: 어스퀘이크(Q)·철골 투척(E)·헐크 포효(F)·토네이도 스핀(T)·기가 스톰프(G) 중 택1 — 전부 모으면 레벨업 모드.
- **좀비 4종**: 워커 · 러너(빠름, 3~) · 브루트(거구·점수 2.2배, 6~) · 크롤러(낮게 기어옴, 9~) — 스테이지가 오를수록 험한 놈들이 섞이고, 피부톤·복장·안전모/모자가 제각각.
- **분노 변신(R)**: 게이지를 채워 발동하면 붉은 폭주 형태로 변신, 좀비 떼가 몰려오고 처치할수록 분노 지속 연장.
- 스테이지가 오를수록 **부술 것이 늘어난다** — 동상(3)·네온 광고탑(5)·급수탑(7)·타워 크레인(9)·마천루(11)가 차례로 등장하고, 거대 구조물일수록 훨씬 단단하다.
- 테마 5종 순환(도심·노을 항구·네온 밤거리·폭풍 전야·군사 기지) — **테마별 BGM 무드**(에픽 록/서정/신스웨이브/긴장/행진곡)와 조성이 함께 바뀐다.
- 히트스톱·슬로모션·줌킥·날아가는 차량 물리·화염/연기/파편 — 전부 외부 리소스 없는 단일 파일 (사운드도 WebAudio 신디사이저).

## 파일

- `index.html` — 배포용 (Vercel이 그대로 서빙). **`hulk-smash.html`에서 생성됨.**
- `hulk-smash.html` — 소스 (Claude 아티팩트 형식: 문서 래퍼 없이 본문만).

수정은 `hulk-smash.html`에 하고, `index.html`은 본문을 `<!doctype html>` 래퍼로 감싸 재생성한다. 배포 채널은 둘: GitHub push → Vercel 자동 배포, 그리고 Claude 아티팩트 재게시.
